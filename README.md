# Oracle
A collection of oracle database administration scripts for day-to-day DBA activities,troubleshooting,monitoring,performance analysis,DataGuard,RAC,ASM,Exadata and Automation

This repository is intended to serve as a practical reference for oracle DBAs,production support engineers and database administrators who need ready-to-use SQL and Sheel scripts for common Oracle administration tasks.
